# ADR 0003 · Bootstrap commands and Telegram service

## Context

Phase 0 requires a cleanly starting bot container and a seed command skeleton. The repository rules prohibit fake business behavior, and Phase 0 has no inventory, payables or recipes.

## Decision

Run the bot as a health-checked process that waits for shutdown and does not contact Telegram. Install seed_demo and reconcile_stock with explicit CommandError results until their required models exist. Each command leaves the database untouched.

## Consequences

The Compose topology can be checked without Telegram credentials. Inventory reconciliation is delivered with the ledger in Phase 1, Telegram behavior in Phase 5, and full demo data in Phase 7.
