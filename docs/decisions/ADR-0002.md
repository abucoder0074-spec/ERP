# ADR 0002 · Phase 0 offline access

## Context

The ERP should install as a PWA and tolerate network interruptions. Phase 0 has only a signed-in shell, and factory phones may be shared.

## Decision

Cache the public offline page and its CSS. Use the network for dashboard, login and logout. Disable HTMX history storage and send no-store on the dashboard and login. Serve the app manifest and service worker from public read-only routes. Default the ERP to Uzbek even when a browser sends a different system language. Use the language cookie for explicit choices.

## Consequences

Users can see a translated offline page and retry after reconnecting. Business read views and their offline access rules are deferred to the phases that introduce the data.
