# ADR 0004 · Inventory posting and valuation

## Context

Posting can span multiple batches and locations. Retries and concurrent stock issues must preserve the physical balance, valuation, and audit trail.

## Decision

Use PostgreSQL transactions with a consistent lock order. Lock touched locations by primary key, then items by primary key, before inspecting stock. A client UUID identifies the posting. Reusing it with a different actor or payload is an error. Each movement has its own unique UUID and an ordinal within the posting.

Use a moving weighted average per item and warehouse. Store exact extended carrying value at five decimal places and round the displayed movement unit cost to two places with ROUND_HALF_UP. When an issue empties a warehouse position, consume the remaining carrying value to avoid residuals. Transfer the exact carrying value. Reverse the whole posting, including both sides of transfers, through compensating movements. Reject reversals that would make stock or warehouse value negative or leave value on a zero-stock position. Stocktake snapshots use movement watermarks and require a recount after intervening movement.

An expiry date is valid through that date in Asia/Tashkent. Undated approved batches sort last. Explicit FEFO overrides still exclude expired and unapproved batches. Alternative quantities convert to base units with exact Decimal arithmetic. Compute the three-place HALF_UP result and reject any nonzero precision loss.

Warehouse keepers may write off up to the configured per-posting value. Managers and Admin can post larger write-offs, approve stocktakes and quality transitions, override FEFO, and reverse postings. A stocktake approver must differ from its counter.

## Consequences

The item row serializes valuation across warehouses. A warehouse carrying value can be reconciled independently of the physical batch-location balances. Phase 1 operates in UZS and does not implement procurement receipt matching. Browser camera scanning uses native barcode detection where available and retains manual entry on all browsers.
